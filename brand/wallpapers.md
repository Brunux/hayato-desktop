# Wallpapers

The three pictures each built-in theme cycles, and where each one came from.
`scripts/fetch-wallpapers.py` is the manifest: it fetches, converts and installs
them, and `--check` proves every theme still has exactly three.

Pictures imported from the omarchy tree (`omacom/omarchy`, branch `quattro`, MIT)
keep the path they came from. Pictures marked *shipped* predate the import and
carry no upstream path in this repository.
